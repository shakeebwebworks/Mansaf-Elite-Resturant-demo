# Mansaf Elite — Restaurant Website Concept

A responsive React + Vite website concept for Mansaf Elite Restaurant, Belagavi.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open the terminal in this folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL shown by Vite (usually http://localhost:5173).

To create a production build:

```bash
npm run build
npm run preview
```

## Included

- React, Framer Motion, Lenis smooth scrolling, Lucide icons
- Responsive desktop and mobile navigation
- Animated hero and scroll-reveal sections
- Interactive menu category tabs
- Click-to-expand photo gallery
- Demo reservation form
- Google Maps search link and Instagram profile link
- Brand logo and six photo crops taken from the Instagram screenshot supplied in this conversation

## Important before presenting as a live client website

The supplied Instagram screenshot is the only image source currently available. The logo and food/interior images in `public/images/` are crops from that screenshot, not original full-resolution uploads. Ask the restaurant for the original logo and high-resolution food/interior photographs before launch.

The restaurant has not supplied a phone number, WhatsApp number, verified address/pin, opening hours, full menu, dish ingredients, or prices. Those have deliberately not been invented. The reservation form is a visual demo only and does not send a booking. Connect it to the restaurant's approved WhatsApp/booking workflow after receiving the correct details.

The current map link searches Google Maps for “Mansaf Elite Restaurant Belagavi”; confirm the exact listing and pin with the owner.
